# JustClock

A minimalist, distraction-free clock, timer, and stopwatch designed for focus, presentations, and daily display.

## Key Features

- **Fullscreen Display:** Clean interface that hides unnecessary navigation elements for ultimate readability.
- **Timer & Stopwatch:** Built-in precise timer and stopwatch tools for productivity and exercise.
- **Keep Screen Awake:** Prevents your device display from timing out while active.
- **Customizable Themes:** Easily adjust colors and settings to fit your setup.
